# Կափառնա — Համապատասխանեցում

Игра «Найди пару» для воскресной школы: две команды по очереди открывают карточки на сенсорной доске
и ищут библейского героя и его предмет. 25 пар, 50 карточек, 15 минут. Правила и список пар: [docs/spec.md](docs/spec.md).

## Как запустить на доске

- **По ссылке:** https://claude.ai/artifact/XinCdiS1BkoWonags8y3cV (приватная страница: на доске нужно войти в свой аккаунт claude.ai или открыть доступ через меню Share).
- **Без интернета:** скопируйте файл `dist/index.html` на флешку или на доску и откройте его в браузере (Chrome или Edge). Все картинки, шрифты и звуки уже внутри файла.

После нажатия «Սկսել խաղը» браузер переходит в полноэкранный режим. Кнопка с квадратиком в шапке включает и выключает его.

## Как играть

- Ребёнок касается двух закрытых карточек.
- Верная пара: команде 1 очко, карточки остаются открытыми с эмблемой команды, ходит та же команда.
- Неверная пара: карточки видны около двух секунд, закрываются, ход переходит другой команде.
- Игра заканчивается, когда найдены все 25 пар или вышло время. В последнюю минуту звучит сигнал, последние 10 секунд тикают.

## Музыка и звуки

- **Фоновая музыка** играет всю игру: оригинальная весёлая мелодия в духе армянского народного танца (дудук, канон, бас и бубен). Она синтезируется прямо в браузере, поэтому работает без интернета. В последнюю минуту музыка ускоряется, на паузе замолкает, в конце уступает место фанфарам.
- **Звуковые эффекты:** переворот карточки, закрытие неверной пары, верная пара, ошибка, свой позывной у каждой команды при смене хода, начало игры, сигнал «осталась 1 минута», отсчёт последних 10 секунд, гонг по окончании времени, фанфары и аплодисменты победителю.
- **Выключатели:** музыку и эффекты можно включать отдельно на стартовом экране и кнопками ♪ и 🔊 в шапке игры. Выбор запоминается на этом устройстве.
- Браузеры разрешают звук только после первого касания, поэтому звук появляется с нажатием «Սկսել խաղը».

## Для ведущего

- **Перед игрой:** названия команд, длительность, кто начинает, показывать ли подписи под предметами. Подписи под героями есть всегда.
- **Пауза** (кнопка ⏸ в шапке): продолжить, передать ход другой команде, досрочно завершить, начать заново. Завершение и новая игра требуют второго нажатия.
- **После игры:** «Բացել բոլոր քարտերը» открывает все оставшиеся карточки, «Բոլոր զույգերը» показывает все 25 пар.
- Если страница случайно перезагрузилась, на стартовом экране появится «Շարունակել նախորդ խաղը», игра продолжится с паузы.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тесты правил игры
npm run build    # dist/index.html (один файл) и dist/artifact.html
```

- Правила игры: `src/game/engine.ts`, тесты рядом.
- Звук: `src/audio/` (инструменты, музыка, эффекты, переключатели каналов).
- Пары и подписи: `src/data/pairs.ts`. Весь текст интерфейса: `src/i18n.ts`.
- Портреты героев рисуются кодом: `src/art/heroes.ts`. Предметы — SVG-файлы в `src/art/objects/`, стиль описан в [docs/art-style.md](docs/art-style.md).
- `npm run sheet` и `node scripts/hero-sheet.mjs` собирают превью всех рисунков в PNG (macOS).
